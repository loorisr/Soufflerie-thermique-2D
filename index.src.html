Numérique

Le pas de temps est choisi pour que la vitesse de référence reste à Mach 0,12 sur le réseau. L'écoulement utilise un collisionneur MRT avec un modèle LES de Smagorinsky ; la viscosité de base est relevée au minimum stable du maillage. La diffusivité thermique n'est relevée que là où l'écoulement est rapide. Affiner la grille (GPU) rapproche les résultats de la physique ; les valeurs restent indicatives.
